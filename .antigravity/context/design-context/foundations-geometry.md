# Erythro.ai — Геометрия: Сетка, Отступы, Скругления, Тени и Эффекты бэкграунда

 Все пространственные параметры UI должны строго подчиняться правилам ниже.

## 1. Контейнер и Сетка (Grid Scale)
* **Макет верстки (Desktop)**: Базовое разрешение экрана — 1920px.
* **Ширина контентной области (Ограничитель)**: Строго **1170px** (используй `max-w-[1170px] mx-auto px-[30px]`)].
* **Колоночная система**:
  * Количество колонок: **12 columns** (`grid-cols-12`)
  * Ширина одной колонки: **70px** * Межколоночный отступ (Gutter / Margin): **30px** (`gap-[30px]`) 
* **Адаптивные брейкпоинты**:
  * Tablet: `768px` / `1024px` 
  * Mobile: `360px` – `390px` 

## 2. Линейка отступов (Spacing Scale) 
Запрещены любые случайные (hardcoded) значения. Вся верстка строится на фиксированном шаге:
* `spacing/0` = 0px
* `spacing/8` = 8px
* `spacing/16` = 16px
* `spacing/30` = 30px (Основной шаг для сетки, секций и маржинов поп-апов) 
* `spacing/40` = 40px
* `spacing/60` = 60px
* `spacing/100` = 100px

## 3. Скругления углов (Radius Scale) 
* `Radius/xs` = **2px** (Маленькие элементы, чекбоксы)
* `Radius/sm` = **5px** (Инпуты, теги)
* `Radius/md` = **10px** (Кнопки, стандартные карточки, поля ввода)
* `Radius/lg` = **20px** (Большие контентные блоки, банеры)
* `Radius/xl` = **40px** (Смягченные интерфейсные блоки)
* `Radius/2xl` = **80px** / Max (Круглые кнопки, переключатели, аватарки)

## 4. Спецификация Эффектов (Shadows из Figma)
Реализуй тени строго по параметрам макета (используй `Coal/Alpha` и `Erythro/Alpha`):
* **Button Primary Dark**: `X:0, Y:3, Blur:20, Spread:0`, Цвет: `Gold/500` (`#FFE9C7`) с opacity 30%.
* **Button Primary Light**: `X:0, Y:3, Blur:20, Spread:0`, Цвет: `Erythro/500` (`#E52421`) с opacity 50%.
* **Button Secondary (Dark & Light)**: `X:0, Y:3, Blur:20, Spread:0`, Цвет: `Gold/500` (`#FFE9C7`) с opacity 30%.
* **Card Services Dark**: `X:0, Y:5, Blur:20, Spread:0`, Цвет: `Coal/900` (`#0D0D0D`) с opacity 30%.
* **Card Services Light**: `X:0, Y:5, Blur:20, Spread:0`, Цвет: `Coal/900` (`#0D0D0D`) с opacity 20%.
* **Button Tertiary (Dark & Light)**: `X:0, Y:3, Blur:20, Spread:0`, Цвет: `Gold/100` (`#FFFFFF`) с opacity 30%.

## 5. Важное правило для RTL (Локализация на Иврит)
Поскольку один из трех языков проекта — иврит, **строго запрещено** использовать жесткие направленные классы Tailwind, такие как `pl-*`, `pr-*`, `ml-*`, `mr-*`, `left-*`, `right-*`.
* **Требование**: Используй логические свойства Tailwind: `ps-*` (padding-start), `pe-*` (padding-end), `ms-*` (margin-start), `me-*` (margin-end), `start-*`, `end-*`.
* Направление flex-контейнеров: при `dir="rtl"` (для иврита) классы `flex-row` автоматически отзеркалят элементы, если ты не захардкодил `left/right`.

## 6. Эффекты бэкграунда (Background Noise Effect)
Для придания премиальной текстуры ключевым блокам интерфейса используется процедурный оверлей шума поверх фоновых заливок секций.
* **Применяемость**: Обязательно к рендерингу в бэкграундах блоков **Solution**, **Let`s talk**, и **Services**.
* **Параметры эффекта (Figma Noise Plugin)**:
  * **Режим (Type)**: `Mono` (Однотонный шум)
  * **Размер шума (Noise size)**: `X: 1`, `Y: 1`
  * **Плотность (Density)**: `100%`
  * **Цвет (Color)**: Чистый черный `#000000` (`Coal/900`) с **интенсивностью / opacity: 5%**.
* **Инструкция для реализации в коде**: Эффект должен быть реализован через CSS-оверлей (`background-image` с закодированным SVG-шумом или повторяющейся бесшовной PNG-текстурой малого веса) со свойством `mix-blend-mode: multiply` или прозрачностью `opacity-[0.05]`, располагаясь строго между фоновым цветом секции и контентным слоем.
