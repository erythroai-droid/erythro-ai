# Erythro.ai — Типографика и Правила Локализации

Соблюдай жесткую иерархию текстовых стилей. Размеры указаны в формате: `font-size / line-height` (в пикселях).

## 3. Трехъязычный Стресс-тест и Направление Текста (Локализация)

Сайт поддерживает 3 языка: **Английский (EN), Русский (RU), Иврит (HE)**.

### Правило Длины Текста (+40%):

Русский текст в среднем на 40% длиннее английского. Запрещено задавать фиксированную ширину (`w-[200px]`) кнопкам, элементам меню и табам. Контейнеры должны автоматически расширяться, используя **Auto Layout** (Flexbox / Grid в Tailwind).

### Правило Направления Текста (LTR vs RTL) и Шрифтов:

- **EN, RU**: Направление слева направо (`dir="ltr"`).
    
- **Иврит (HE)**: Направление справа налево (`dir="rtl"`).
    
- **Шрифтовое правило для HE**: При переключении на локаль `he` (иврит) для всего контента **обязательно** должен использоваться системный и полностью поддерживающий RTL-раскладку шрифт **Inter**. Это критично для точного соответствия геометрии макета и предотвращения визуальных багов отображения символов.
    
- При переключении на иврит текстовые заголовки, иконки стрелок (например, `→` должна стать `←`) и расположение элементов в хэдере/футере должны зеркально менять свою позицию. Настраивай корневой тег `html` на динамический атрибут `dir={currentLocale === 'he' ? 'rtl' : 'ltr'}`.
