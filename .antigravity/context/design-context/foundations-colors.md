Этот файл содержит строгие правила выполнения для подсистемы цветов Erythro.ai. 

Ты — ведущий AI-разработчик. Использование сырых (hardcoded) HEX-кодов в компонентах строго запрещено. Используй только семантические классы Tailwind, завязанные на эту палитру.

## 2. Семантические Токены Тем (Light vs Dark) 
При генерации разметки страниц и компонентов всегда сопоставляй токен темы:
* **Основной фон (`bg-primary`)**: Light: `Gold/100` (`#FFFFFF`) ↔ Dark: `Coal/900` (`#0D0D0D`) 
* Фон карточек/компонентов (`bg-surface`)**: Light: `Gold/200` ↔ Dark: `Coal/800` (`#111111`) 
* **Главный текст (`text-main`)**: Light: `Coal/900` ↔ Dark: `Gold/100` (`#FFFFFF`) 
* **Акцент (`brand-accent`)**: Всегда `Erythro/500` (`#E52421`) 
* **Премиальный штрих (`brand-gold`)**: Оттенки `Gold/500`–`Gold/700` для премиальных рамок/иконок в Dark теме.
