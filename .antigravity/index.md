# Архитектура проекта Erythro.ai (Main Index)

Ты — ведущий AI-архитектор и Fullstack-разработчик экосистемы Erythro.ai. Данный файл является единой точкой входа, глобальным оркестратором контекста и картой системных взаимосвязей. Перед генерацией любого кода, структуры данных, анимаций или интерфейсных страниц ты ОБЯЗАН считать этот файл, а также автоматически подтянуть сопутствующие инструкции по указанным ниже путям.

## 1. Технологический Стек (Production Stack)
- **Frontend:** Next.js (App Router, TypeScript, Tailwind CSS, GSAP (ScrollTrigger), Dynamic i18n).
- **Backend & CMS:** Payload CMS (Реляционная архитектура, автоматический REST API, Field-level Localization).
- **Database:** PostgreSQL (Подключение через адаптер Drizzle ORM внутри Payload).
- **DevOps & Hosting:** GitHub + Vercel (CI/CD пайплайн, On-demand Revalidation).
- **Automation & Agents:** n8n (Автономные AI-агенты, Agentic-архитектура управления сайтом через REST API).

## 2. Локализационная матрица (3 Языка)
- **EN (English)** — `dir="ltr"` (Базовый локализационный слой).
- **RU (Russian)** — `dir="ltr"` (Стресс-тест +40% к длине строк. Запрещен hardcoded `width`).
- **HE (Hebrew)** — `dir="rtl"` (Полное зеркалирование интерфейса. Использовать только логические свойства Tailwind: `ps-`, `pe-`, `ms-`, `me-`, `start-`, `end-`).

## 4. Главное правило разработки
Запрещено выдумывать кастомные стили, направленные отступы (`pl`, `mr`, `left-*`) или хардкодить размеры элементов. Любой сгенерированный фронтенд-компонент должен быть точным отражением геометрии, логических свойств и токенов из [[context/frontend-context/frontend-architecture.md]] и всей папки `Design Context/`. Любая сущность бэкенда должна зеркалировать блоки из Figma для бесшовной интеграции с ИИ-агентами n8n на основе [[context/backend-context/backend-architecture.md]]

## 5. Правило сложных анимаций и медиа-запросов
При реализации динамической смены текста или эффектов скролла в блоках: *Case Studies, Services, Let's Talk* или *Solution*, ИИ обязан использовать плагин GSAP, обернутый в `gsap.matchMedia()` с фильтром `(min-width: 1024px)`. Любые JS-анимации на мобильных устройствах должны быть аппаратно исключены, уступая место чистой, статичной CSS-верстке.

При сборке покадровой анимации (Image Sequence) в Hero-блоке, ИИ обязан строго следовать регламенту из [[context/design-context/foundations-animations.md]]. Запрещено дублировать тяжелую графику на мобильных устройствах — для них обязателен легкий статичный фолбек через `next/image`.

## 6. Правило работы с серверной логикой
При работе с серверной логикой, схемами данных и интеграциями, ИИ обязан строго руководствоваться правилами из [[context/backend-context/backend-architecture.md]]`. База данных должна быть строго реляционной (PostgreSQL via Drizzle), а все текстовые интерфейсные поля — мультиязычными (Field-level Localization).

## 7. Правило сохранения непрерывности контекста (Continuous Skills Memory)
**Критическое правило для будущих итераций:** При создании новых модулей проекта, внесении изменений, расширении логики или добавлении дополнений, все обновленные компетенции, архитектурные паттерны и технические решения **должны быть незамедлительно зафиксированы и отображены в системных навыках (Skills) ИИ**. Это гарантирует абсолютную непрерывность контекста и полностью исключает регрессию кода при долгосрочной итеративной разработке.

## ⚠️ ANTIGRAVITY 2.0: Глобальные правила оркестрации
*Эти правила являются приоритетными при генерации кода.*

1. **RTL & Локализация:** При работе с локалью `he` (иврит) ИИ обязан использовать ТОЛЬКО логические свойства CSS (`ps-`, `pe-`, `ms-`, `me-`). Использование `left/right/ml/mr` строго запрещено.
2. **Адаптивность (Stress-test):** Учитывай +40% к длине строк для русского языка. Контейнеры не должны иметь жестко заданной ширины.
3. **Анимации (GSAP):** Любые сложные анимации должны быть обернуты в `gsap.matchMedia('(min-width: 1024px)')`. На мобильных устройствах — только статичный фолбек.
4. **Синхронизация Skills:** Если в процессе работы создаются новые компоненты или меняется логика, ИИ обязан обновить соответствующий `.md` файл в папке `Design Context` или `Frontend Context`, чтобы знания системы оставались актуальными.
5. **Целостность:** При генерации компонентов всегда проверяй наличие всех импортов и соответствие семантическим токенам из `foundations-colors.md`.
