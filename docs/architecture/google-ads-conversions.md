# Google Ads: порядок подключения конверсий

Чеклист для следующего сайта. Эталон на erythro.ai: `AnalyticsBootstrap`, `AnalyticsLoader`, `src/lib/adsConversion.ts`, CSP в `next.config.ts`.

Один тег Google на сайт. События конверсий — отдельные вызовы `gtag('event', 'conversion')` в момент успеха, не при открытии страницы.

## 1. В Google Ads

1. «Цели» → «Конверсии» → источник «Конверсии на сайте». Телефонные звонки не включать, если их не отслеживаем.
2. Категория по смыслу: «Покупка» только для оплаты, «Отправка формы для потенциальных клиентов» для заявки. Не вешать покупку на загрузку лендинга.
3. Создание: **«Вручную, с добавлением кода»**. «Автоматически, без кода» считает заход на URL, а не успешную отправку.
4. На каждое действие одно основное. Импорт из GA4, если событие с сайта не шлётся, переключить в **«Дополнительные»**. Два основных в одной цели дают «Неверная конфигурация» / «Требуется действие».
5. Из сниппета забрать только `send_to` (`AW-…/метка`). Базовый тег из письма Google второй раз не вставлять.

## 2. Тег в коде

1. Один раз в `<head>`, сырыми `<script>`, чтобы проверка Ads видела `gtag/js?id=AW-…` в HTML. `next/script` и загрузка только после «Принять» проверку не проходят.
2. Сразу после загрузчика: `dataLayer`, `gtag`, Consent Mode **default denied** (`ad_storage`, `ad_user_data`, `ad_personalization`, `analytics_storage`), `gtag('js', new Date())`, `gtag('config', 'AW-…')`.
3. Второй `gtag/js` не грузить. GA4 `gtag('config', 'G-…')` — после согласия, тем же `gtag`.
4. По «Принять» — `gtag('consent', 'update', …)` со всеми четырьмя хранилищами `granted`. По «Отклонить» — `denied` и очистка `_ga*`, `_gcl_*`.
5. Для уже принявших согласие вызвать `consent update` при загрузке, не только по клику на баннер.

## 3. Событие конверсии

Вызывать только после успеха на сервере, один раз на заявку/оплату.

- `send_to` — метка из Ads.
- `transaction_id` — id заявки. Повтор в том же браузере глушить через `localStorage`.
- Для покупки: `value` и `currency` из суммы оплаты. Страница — возврат после оплаты (`/order/success`), когда статус стал `paid`, не момент открытия URL.
- Для заявки: вешать на **ту форму, куда ведёт кампания**. На erythro.ai это `/audit`, не только `/order/audit-free`.
- `new_customer` не слать, если новый клиент в данных не определяется.

Без согласия событие уходит без cookie. В отчётах такие конверсии частично смоделированы. Тестовый прогон делать после «Принять».

## 4. CSP

Разрешить цепочку, не только `googletagmanager.com`. Chrome в отчёте пишет **первый** URL, а блокирует редирект (для Израиля часто `www.google.co.il`).

`script-src`: `www.googletagmanager.com`, `www.google-analytics.com`, `www.google.com`, `www.google.co.il`, `www.googleadservices.com`, `googleads.g.doubleclick.net`.

`connect-src`: те же плюс `www.googletagmanager.com`, `*.google.com`, `www.google.ru`, `*.g.doubleclick.net`, `stats.g.doubleclick.net`, `pagead2.googlesyndication.com`, `ad.doubleclick.net`, региональный хост Analytics.

`img-src https:` уже закрывает пиксели.

## 5. Текст политики

В политике cookie написать, что тег Google на сайте всегда, а измерительные cookie Ads/Analytics включаются только после согласия.

## 6. Проверка

1. Задеплоить. На проде в заголовке CSP должны быть новые хосты.
2. Tag Assistant на **странице кампании**, в новом окне, после «Принять».
3. Успех: в списке событие `conversion`, в «Отправленных обращениях» карточка «Конверсия» с `AW-…`, консоль без CSP.
4. «Просмотр страницы», «Ремаркетинг» и «Consent Update» конверсией не являются.
5. В таблице Ads статус «Неактивно» и предупреждение кампании «Не завершена настройка» держатся несколько часов, иногда до суток. Дата в отчёте часто не включает сегодня.
6. Пока идёт обучение ставок, кампанию и цели не переключать. Повторные тестовые заявки не слать: они портят обучение, а на бесплатном аудите ещё и упираются в лимит (один домен / email / IP на 7 дней).

## 7. Если покупатель не вернулся на сайт

Событие со страницы «спасибо» не сработает. Тогда офлайн-конверсия из платёжного вебхука (Make). На erythro.ai это не сделано.
