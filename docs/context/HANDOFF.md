# Handoff protocol

Общая память для Cursor, Claude, Gemini, Grok и любой другой модели. Память чатов между сервисами не передаётся. Общая оперативная память — файлы в этом репозитории.

Канон правил: [`AGENTS.md`](../../AGENTS.md). Карта знаний: [`docs/RAG_INDEX.md`](../RAG_INDEX.md). Стек: [`docs/PLAYBOOK.md`](../PLAYBOOK.md) §1. Отложенный бэклог: [`docs/PLAN-deferred.md`](../PLAN-deferred.md).

## Старт сессии

Каждый агент, в любой среде, до планирования и правок:

1. Прочитать [`docs/context/NOW.md`](./NOW.md) — файл последних изменений и текущей эстафеты.
2. Прочитать [`AGENTS.md`](../../AGENTS.md) и дальше соблюдать его.
3. Брать шаг из `NOW.md` только если пользователь не задал другую задачу. Сообщение пользователя важнее файла.

Пока оба файла не прочитаны, код не менять.

## Конец этапа

Когда этап изменил код или решение, или пользователь просит передать работу:

1. Обновить `NOW.md`: что сделано, что осталось, конкретный следующий шаг, блокеры, затронутые пути. Держать файл коротким (ориентир — до 150 строк). Закрытые пункты удалять: архив — история git.
2. Решение, которое должно пережить сессию, записать в `docs/architecture/` или `docs/infrastructure/` и скопировать в Obsidian. В `NOW.md` оставить только ссылку.
3. Исправленный баг — в `docs/PITFALLS.md` и в `D:\Obsidian\Knowledge-Base\05-Glossary-FAQ\pitfalls-troubleshooting.md`.
4. Коммит и push — только по просьбе пользователя. Для одного лишь обновления эстафеты подходит сообщение `ai: handoff`.

`NOW.md` в Obsidian не копировать: это черновик сессии. Этот протокол — устойчивый документ, его копия лежит в базе знаний.

## Кто какой файл читает сам

| Среда | Что подхватывается без просьбы | Что агент обязан открыть |
|---|---|---|
| Cursor | `.cursorrules` (тот же текст, что `AGENTS.md`) и `.cursor/rules/session-handoff.mdc` | `docs/context/NOW.md` |
| Claude Code | `CLAUDE.md` | `NOW.md`, затем `AGENTS.md` |
| Gemini CLI | `GEMINI.md` | `NOW.md`, затем `AGENTS.md` |
| Веб-чат (Gemini, Grok, Claude.ai) без диска | ничего | вставить блок ниже и приложить `NOW.md` |

`CLAUDE.md` и `GEMINI.md` — короткие входы. Не копировать в них текст `AGENTS.md`: три полные копии уже расходились.

## Промпт для чата без репозитория

Приложить `docs/context/NOW.md` и файлы, которые предстоит менять. Весь репозиторий не прикладывать.

```markdown
Ты продолжаешь работу над репозиторием erythro-ai.
Последние изменения: [содержимое docs/context/NOW.md]
Правила: [содержимое AGENTS.md, если файл тоже приложен]
Задача: [конкретный шаг].
По завершении выдай обновлённый docs/context/NOW.md.
```

## Чего не заводить

Отдельный обзор архитектуры, журнал ADR и журнал смены моделей. Архитектура уже в `docs/`, причина решения — в том архитектурном документе, который её описывает, смена модели — в шапке `NOW.md` и в git.

Ветка называется по задаче. Имя модели в имени ветки не используется.

## Если файл и код расходятся

Верным считается код. `NOW.md` поправить в ту же сессию.
